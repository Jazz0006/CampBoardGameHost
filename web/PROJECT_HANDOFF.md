# 营地桌游主持助手 Web 版交接说明

## 项目定位

这是 Android 原生版“营地桌游主持助手”的 Web/PWA 第一版原型。目标是让用户不需要安装 App，只要访问网页即可使用，并且支持 iPhone、Android、电脑浏览器。

本版本采用纯静态文件实现：

- `index.html`
- `styles.css`
- `app.js`
- `manifest.webmanifest`
- `sw.js`
- `app-icon.svg`

部署到 HTTPS 静态站点后，浏览器会通过 Service Worker 缓存应用外壳，实现离线打开。用户数据保存在当前浏览器的 `localStorage` 中。

## 当前 Web 版已经实现的功能

### 通用能力

- 中文 / 英文界面切换。
- 常用玩家保存。
- 临时玩家加入。
- 座位顺序管理。
- 本地状态自动保存。
- 导出当前状态备份 JSON。
- PWA manifest。
- Service Worker 离线缓存。
- 手机优先的响应式界面。

### 谁是卧底

- 设置平民词、卧底词、卧底人数、白板人数。
- 根据当前座位随机发身份。
- 每位玩家可点击自己的卡片，全屏私下查看词语。
- 支持重新开局。

### 狼人杀

- 根据玩家人数生成基础身份：狼人、预言家、女巫、猎人、村民。
- 夜晚步骤导航：
  - 狼人行动；
  - 预言家查验；
  - 女巫行动；
  - 天亮宣布。
- 提供法官隐藏身份表。
- 目前是基础流程版本，还没有完整投票、警长、遗言、技能次数管理。

### 血染钟楼：暗流涌动

当前 Web 版重点实现了血染钟楼说书人助手。

已实现：

- 暗流涌动完整角色池：
  - 镇民：洗衣妇、图书管理员、调查员、厨师、共情者、占卜师、送葬者、僧侣、守鸦人、处女、猎手、士兵、市长。
  - 外来者：管家、酒鬼、隐士、圣徒。
  - 爪牙：投毒者、间谍、男爵、猩红女郎。
  - 恶魔：小恶魔。
- 按玩家人数生成角色分布。
- 男爵会增加外来者、减少镇民。
- 酒鬼会显示为一个不在场镇民。
- 恶魔获得 3 个未上场好人角色作为伪装身份。
- 首夜导航：
  - 爪牙信息；
  - 恶魔信息；
  - 占卜师红鲱鱼；
  - 洗衣妇；
  - 图书管理员；
  - 调查员；
  - 厨师；
  - 共情者；
  - 占卜师；
  - 管家；
  - 间谍。
- 后续夜晚导航：
  - 投毒者；
  - 送葬者；
  - 管家；
  - 共情者；
  - 占卜师；
  - 恶魔行动；
  - 守鸦人。
- 每个夜晚步骤都区分真实行动和占位步骤。
- 每个步骤都显示：
  - 当前步骤；
  - 是否真实行动；
  - 需要唤醒谁；
  - 说书人要做什么；
  - 要告诉玩家什么；
  - 新手解释；
  - 完成下一步按钮。
- 夜晚信息可全屏展示给玩家。
- 展示卡只显示玩家应看到的信息，不显示隐藏答案或说书人备注。
- 天亮宣布页面。
- 白天管理：
  - 存活人数；
  - 处决所需票数；
  - 当前最高票；
  - 提名；
  - 投票；
  - 结束白天确认；
  - 处决。
- 猎手一次性能力。
- 基础胜负检查：
  - 恶魔死亡，善良阵营获胜；
  - 只剩 2 名玩家且恶魔存活，邪恶阵营获胜；
  - 圣徒被处决，邪恶阵营获胜；
  - 3 人存活且无人处决并有市长，善良阵营获胜；
  - 猩红女郎在条件满足时接替恶魔。
- 说书人总览页显示真实身份、显示身份和存活状态。

## 当前已知限制

- Web 版是第一版静态原型，还没有和 Android 原生代码共享逻辑。
- 数据只保存在当前浏览器，换设备不会自动同步。
- 已有“导出备份”，但尚未实现“导入备份”按钮。
- 血染钟楼角色能力仍是简化实现：
  - 僧侣保护尚未完整接入恶魔击杀结算。
  - 处女能力尚未接入提名事件。
  - 隐士错误登记、酒鬼/投毒导致错误信息尚未做高级裁定。
  - 士兵免疫恶魔击杀尚未完整结算。
  - 间谍查看魔典是提示型，没有独立安全展示模式。
- 狼人杀 Web 版目前只有基础夜晚流程，尚未达到 Android 版法官助手深度。
- 谁是卧底目前是基础发牌和查看词语，尚未加入完整轮次、投票和淘汰管理。
- PWA 离线缓存需要通过 HTTPS 或本地服务器访问；直接双击 `index.html` 可以使用核心功能，但 Service Worker 不会在 `file://` 下工作。

## 下一步目标建议

### 第 1 优先级：让 Web 版可稳定试玩

- 加入“导入备份”。
- 加入“重置全部数据”。
- 给血染钟楼增加一键模拟开局测试。
- 增加本地浏览器自动化 smoke test。
- 把血染钟楼的角色生成、夜晚步骤、胜负检查拆成独立模块。

### 第 2 优先级：补齐血染钟楼高级规则

- 僧侣保护结算。
- 士兵不会死于恶魔。
- 处女第一次被镇民提名时处决提名者。
- 投毒者/酒鬼导致错误信息的说书人选择界面。
- 隐士可能登记为邪恶或恶魔。
- 间谍可安全查看魔典。
- 死亡玩家亡者票管理。
- 旅行者、陌客、更多剧本支持。

### 第 3 优先级：增强狼人杀和谁是卧底

- 狼人杀：
  - 遗言设置；
  - 白天发言顺序；
  - 投票与放逐；
  - 女巫药品次数；
  - 守卫、白痴、骑士等高级身份。
- 谁是卧底：
  - 发言轮次；
  - 投票；
  - 淘汰；
  - 胜负判断；
  - 多词库随机抽词。

### 第 4 优先级：产品化

- 部署到 GitHub Pages / Netlify / Cloudflare Pages。
- 加 HTTPS 后验证 PWA 离线安装。
- 添加“添加到主屏幕”引导。
- 增加隐私说明：所有数据默认只保存在本机浏览器。
- 考虑把 Android 版和 Web 版的规则逻辑统一成共享数据结构。
