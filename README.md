# 露营桌游助手

安卓原生 MVP，当前实现了「谁是卧底」的离线主持流程。

## 当前功能

- 设置 3-12 名玩家
- 自定义玩家名字
- 设置卧底人数
- 可选择加入 1 名白板
- 内置离线词库随机抽词
- 手机轮流传给玩家查看自己的词
- 主持人面板记录每轮淘汰玩家
- 每轮淘汰后自动判断游戏是否结束
- 结束后显示胜负结果、触发原因、所有玩家身份和词语

## 打开方式

1. 用 Android Studio 打开本目录：`CampBoardGameHost`
2. 等待 Gradle 同步完成
3. 连接安卓手机或启动模拟器
4. 运行 `app`
