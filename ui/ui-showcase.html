Foundation

交互原则

所有组件都围绕暗光环境、单手持机、敏感信息保护和流程可恢复设计。

  1. 效率优先 一个页面只突出一个主任务。
  2. 状态持续可见 天数、阶段、玩家与进度不会随滚动消失。
  3. 不只依赖颜色 图标、文字和颜色共同表达状态。
  4. 保护隐藏信息 玩家展示模式只渲染对方可见内容。
  5. 危险操作可辨认 处决和结束游戏使用独立危险语义。
  6. 错误可以恢复 返回、撤销、记录和恢复入口始终明确。

Color

语义色彩

深黑和炭灰承载长时间操作；黄铜用于当前步骤，暗红只用于危险与邪恶。
