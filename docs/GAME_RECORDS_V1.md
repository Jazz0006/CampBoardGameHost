# 游戏记录第一版

主持工具中的“角色身份”TAB 已替换为“游戏记录”，当前身份继续从方桌查看。

## 查询方式

- 当前局只读记录，按阶段分组、按全局序号正序排列，进入时定位至最近记录。
- 玩家、类型、阶段三个筛选；玩家筛选包含行动目标、信息接收者和信息涉及的玩家。行动者未保存时不猜测。
- 一行摘要，带箭头的条目可展开查看投票人员、鬼票、失效标记或明确保存的登记裁定。
- 当前局结束后离开前仍可查看；重新开局会清理当前局，不增加跨局档案。

## 当前展示范围（供下一轮删减评审）

| 类型 | 第一版展示 |
|---|---|
| 信息 | 已确认告知的原始内容、能力、接收者，公开信息；复杂信息保留“或/且/非”语义 |
| 行动 | 投毒、保护、攻击、管家主人、猎手开枪、呆瓜选择、市长转移、间谍查看、艺术家问答使用 |
| 提名与投票 | 提名双方、票数；展开查看投票人员和幽灵票 |
| 局面变化 | 死亡、处决、无人处决、角色和阵营变化、结束原因 |
| 配置 | 红鲱鱼设置/清除、恶魔伪装身份 |

阶段推进只作为分组，不单独占一条记录。第一版保留已确认行动与实际告知两种不同事实，不用相邻顺序猜关联并合并。后续可重点评估艺术家使用与回答、公开状态信息与行动结果是否需要有明确关联的精简展示；不因此删除 Session 原始记录。

## 数据与边界

唯一输入是当前 `ClocktowerSessionUiState.snapshot`。行动和信息共享全局序号，生成临时展示行；不新增存档、事实写入、AI 请求或恢复逻辑。预览、候选和 AI 建议均不进入记录。

玩家姓名来自当前 Session 的稳定座位映射，历史能力只使用记录中的能力来源，不拿当前身份冒充历史身份。信息表示实际收到什么，不保证为真；不根据答案推断未记录的登记或失效原因。

当前无法提供完整初始布局、酒鬼分配独立记录、艺术家问题原文和间谍当时魔典快照。缺失内容不补造。

入口沿用主持工具私密全屏层，玩家展示页没有记录入口。查看与返回不改变当前主持步骤。
