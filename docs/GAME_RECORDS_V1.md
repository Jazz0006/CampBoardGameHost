# 游戏记录：精简展示版

事件按全局序号倒序，阶段内同样倒序；默认从顶部查看最新记录。开局配置独立放在所有首夜信息之后，不置顶；红鲱鱼和恶魔伪装展示最新确认值，展开查看历史修改。

角色信息以能力名称开头，目标用座号：洗衣妇信息“士兵，3号或7号”；占卜师信息“3号、7号，有/无”；厨师“1对”。图书管理员无人信息显示“无外来者”。实际收到的内容不变。

隐藏首夜邪恶阵营互认、间谍查看魔典、艺术家使用记录和已由死亡/处决表达的重复公开生死记录。艺术家实际回答仍保留。角色变化通知不重复展示已有变化事件。

提名与其 `vote:<nominationId>` 投票合并，摘要包含票数和投票座号；鬼票在详情中。处女触发仅依据该提名关联的 `:virgin-execution`，不推断角色或登记；处决仍单独显示。合并条目按投票确认位置排序，尚无投票时明确显示未完成。

保留类型、阶段筛选；按用户决定移除玩家筛选及其专用关联数据。原始 Session、JSON、规则、AI 和恢复逻辑不变，精简只作用于展示。红鲱鱼在 Next 前的改选仅是草稿，只记录最终确认值。复用原有一项数据展示回归，不增加测试数量；保留恢复、实际私密回答及只读保障。

验证：最终代码通过现有 `ClocktowerGameRecordsTest` 和 Debug APK 构建；未增加测试方法，未重复运行全量套件，未做真机验收。无生产文件或独占测试删除；Session 事实写入链不变。远端 CI 状态不作为本地构建结果的一部分。
