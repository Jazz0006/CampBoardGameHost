# 说书人信息推荐系统离线评审报告

日期：2026-07-18  
范围：阶段六 A——固定局面离线验证  
结论：通过离线质量与性能门槛；待真人专家盲测和产品灰度数据。

## 1. 评审方法

评审数据集包含24个固定《暗流涌动》局面，覆盖：

- 7、8、10、12人；
- 酒鬼与占卜师同时在场；
- 仅酒鬼或仅占卜师在场；
- 不同邪恶座位与环形邻接关系；
- 酒鬼展示为调查员和其他镇民；
- 1名或2名爪牙配置；
- 不同在场角色导致的恶魔伪装候选变化。

旧逻辑基线使用完全确定性的“第一个合法项”策略：第一个合法红鲱鱼、当前或第一个合法酒鬼展示身份、第一组合法调查员候选、角色列表中的前三张合法恶魔伪装。新逻辑使用平衡型推荐。两者使用相同局面、剧本角色表和固定种子。

每个推荐额外执行独立合法性验证。性能数据先进行一次JVM热身，再测量完整三风格推荐耗时。

## 2. 汇总结果

| 指标 | 旧基线 | 平衡推荐 |
|---|---:|---:|
| 合法局面比例 | 100.0% | 100.0% |
| 达到 `RECOMMENDED` 比例 | 58.3% | 100.0% |
| 平均评价分 | 16.46 | 42.58 |
| 平均警告数 | 0.42 | 0.00 |
| 酒鬼调查员信息命中真实邪恶次数 | 7 | 0 |
| 红鲱鱼与酒鬼调查员候选重叠次数 | 7 | 0 |
| 酒鬼调查员指向自己次数 | 0 | 0 |
| 平均关键暴露惩罚 | 4.00 | 6.00 |
| 平均恶魔伪装支持分 | 16.58 | 21.67 |

三种风格的平均实质差异数为 `3.00`，即24个局面均得到三套不同效果签名的方案。

## 3. 性能结果

| 人数 | 平均耗时 | 最大耗时 | 设计目标 |
|---:|---:|---:|---:|
| 7 | 224.9 ms | 244.8 ms | 未单独规定 |
| 8 | 165.3 ms | 275.8 ms | 平均低于200 ms |
| 10 | 218.1 ms | 447.9 ms | 未单独规定 |
| 12 | 206.3 ms | 378.1 ms | 低于500 ms |

本轮通过缓存与恶魔伪装无关的基础评价，避免对同一红鲱鱼和酒鬼信息组合重复计算固定信息。该优化不截断候选、不改变评分或排序，搜索仍覆盖完整合法候选空间。

## 4. 根据报告进行的调整

首轮评审发现2个平衡方案让酒鬼调查员指向自己。该裁定合法，但不适合作为新手默认推荐。因此：

- 保留其合法候选身份；
- 保留评分惩罚和风险解释；
- 将其质量等级降为 `ACCEPTABLE_WITH_WARNING`；
- 新手默认搜索优先选择没有自指风险的 `RECOMMENDED` 方案。

调整后24个平衡方案的酒鬼自指次数从2降为0，其他核心质量指标未退化。

关键暴露惩罚高于旧基线，是因为新算法主动选择具有少量交叉验证价值的候选，而旧基线只是选择座位靠前的玩家。该指标需要在真人盲测中结合“冲突是否可解释”评价，暂不单独增加权重。

## 5. 自动验收结论

- 非法推荐率：0%；
- 固定种子和玩家改名复现率：100%；
- 平衡方案直接推荐比例：100%；
- 三方案差异达标比例：100%；
- 推荐理由均来自结构化 `ScoreItem` 或 `PlanWarning`；
- 8人与12人平均性能达到设计目标；
- 旧手动裁定流程仍可回退。

## 6. 尚未完成的外部验证

离线评分由当前规则和元数据定义，不能替代真人说书人判断。发布前仍需：

1. 邀请至少3名熟练说书人对新旧方案进行匿名、随机顺序盲测；
2. 每个局面记录“直接采用 / 修改后采用 / 不采用”和修改原因；
3. 统计新方案偏好率、默认采用率和最常修改裁定；
4. 仅根据跨评审者一致意见调整权重；
5. 小范围灰度期间保留旧手动模式和一键回退。
