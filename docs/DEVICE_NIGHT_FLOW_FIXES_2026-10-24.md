| 编号 | 真机发现 / 改进 | 原因与最终行为 |

| N1 | 爪牙、恶魔展示后底部出现重复预览文字 | 夜间外壳再次绘制预览摘要。移除两条共用外壳路径中的底部摘要；占卜师、送葬者、守鸦人、贤者等共用途径一并覆盖。保留最后一次预览和 Next 确认门槛。 |

| N3 | 方桌未直观标出本步需要唤醒的玩家 | 共用方桌在座位朝内一侧绘制空心箭头，避开其他座位和中央操作区；依据当前行动者更新，包括死亡触发角色及同时唤醒的多名爪牙。极端受限、无安全空间的布局不强行画出越界箭头。 |
| N4 | 清醒送葬者、守鸦人仍需从全角色列表中选答案 | 新增窄范围只读身份结果解析：根据当前 Session、查询目标和能力状态确定结果。唯一结果直接提供展示按钮且不请求 AI；酒醉、中毒、间谍/隐士有效特殊认知仍保留相应裁量。守鸦人先由玩家选择目标；酒鬼目标返回真实酒鬼身份。 |
| N5 | 送葬者玩家全屏泄露“真实身份是酒鬼”等内部说明；守鸦人同样有风险 | 共用组件将空 displayFooter 回退为说书人 explanation。全部玩家全屏不再渲染说明和页脚；角色揭示只显示告知的角色名，数值/双人等保留必要的实际结果和目标座位。说书人内部酒醉/中毒提示仍保留。 |
| N6 | 厨师 0～5 等纵向选项挤出展示按钮，无法推进 | 酒醉/中毒候选原为 0～玩家人数，且按钮位于同一滚动列表末端。标准 TB 改为 5～9 人 0～2、10～12 人 0～3、13～15 人 0～4 的合理误导候选范围；清醒正常仍仅提供当前局面实际允许的结果。数字改为紧凑可换行网格，选择区独立滚动，展示按钮固定保留，未选择时禁用。 |
| N7 | 厨师特殊认知可能漏掉合法数字 | 原计算把隐士/间谍一次认知同时应用于两侧邻接关系。改为逐条相邻关系分别认知，含首尾邻接；例如两名邪恶之间的隐士可支持 0、1、2，而非只支持 0、2。 |
| N8 | 小恶魔传承后的唤醒仍使用独立旧卡片页 | 移除旧页面，复用当前 Session 座位投影和共用只读方桌，箭头指向新恶魔。中央仅保留唤醒座位与展示按钮；玩家全屏显示“你现在是小恶魔”。实际展示返回后才可确认告知，状态变更或重载后需要重新展示。旧回调不能确认另一份当前状态的通知。 |
| N9 | 白天处决小恶魔、猩红女巫继任后，当晚没有攻击 | 旧小恶魔死亡后仍保留角色；排程取列表中第一个小恶魔，发现死亡便跳过整个角色。因此旧恶魔排在继任者前时漏步骤，反向座位正常。排程、Host 当前行动者和对应中毒查询统一读取活着的小恶魔。白天继任当晚可攻击；夜间自杀传承当晚不重复攻击，下一夜正常攻击。 |
