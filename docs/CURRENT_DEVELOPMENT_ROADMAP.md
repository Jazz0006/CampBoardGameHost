# 当前开发路线

更新：2026-10-17（Australia/Sydney）。本文件是当前执行优先级权威。

## 唯一当前方向：最小 Host

项目所有者已决定删除 Host 游戏规则校验和手动规则/线索辅助，仅保留必要游戏状态、统一记录及基本操作。AI 提供分析/建议，说书人负责规则正确性。具体边界见 [最小 Host 产品合同](MINIMAL_HOST_PRODUCT_CONTRACT_2026-10-17.md)。

先删除冗余，允许明确缺口；不要求先完成替代系统。继续保护数据完整性、确认事实、私密信息和过期 AI 响应隔离，这些不属于游戏规则校验。

## 旧轮次收尾

#315–#328 的 Session 收敛、独立 Recovery/重复文字记录删除、状态收敛与 D1–D5a 局部整理作为下一轮基线保留。它们不代表最小 Host 已实现。

旧路线中“保留规则语义，继续拆分夜间信息准备与 AI 生命周期”的 NEXT 已暂停，不再驱动开发。既有合法性/候选/登记投影不得仅因刚拆出或测试通过而保留。

旧实施证据见 [本轮清理规格](MINIMAL_GAME_STATE_CLEANUP_2026-10-17.md)、[D 阶段历史审计](APP_HOST_STAGE_D_AUDIT_2026-10-17.md)、[D5a 检查点](REGISTRATION_OPTIONS_D5A_2026-10-17.md)。历史文档中的未来任务和规则保留要求由新合同覆盖。

## 2026-10-18 决定：先做自由人工输入，结束清理后才做智能候选

已批准两阶段设计，详见 [人工信息两阶段方案](MANUAL_INFORMATION_TWO_STAGE_PLAN_2026-10-18.md)。当前 M1–M5 的目标是彻底取消旧规则计算及合法性校验：说书人只受格式和对局数据完整性约束，能直接指定任意数字、真假、角色及两座位声明。不得把用户提出的 pair 动态候选、Chef 范围初始化、Empath 邻座校验提前加入本轮。它们全部列入清理之后的 **第二阶段新设计**；旧规则引擎只删除不复制，第二阶段须重新审计并另行授权启动。实际已完成部分请参照 M1c，其他类型尚待迁移。

## M1c 人工标量结果直接输入（2026-10-18）

Draft PR #333 基于 #332：不需要玩家选目标的数字夜间信息已在 MANUAL / AI_ASSISTED 模式下直接输入最终展示的数字，绕过 Host 合法候选清单；占卜师在玩家实际选定两名查询目标后，可由说书人直接选择“有/没有”，不以 Host 推算出的结果过滤。两种展示都转为明确的结构化私密观察，走已统一的 Session 提交流程。没有进行真假推定的人工结果在首夜历史中标记 `SemanticTruth.NOT_APPLICABLE`，不冒充 Host 核实过的真假。AI_AUTOMATIC 的写入约束保持不变。

本批为人工数值和布尔结果的第一段迁移；Chambermaid 的查询后数字、Undertaker/Ravenkeeper/Sage 的角色信息、Washerwoman/Librarian/Investigator 双座位线索，以及残余规则候选/真假推断计算仍需后续整链清除。PR #333 的编译验收必须以其最新代码 HEAD 的 GitHub CI/R2 为准。
