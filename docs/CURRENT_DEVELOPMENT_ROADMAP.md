# 当前开发路线

更新：2026-10-17（Australia/Sydney）。本文件是当前执行优先级权威。

## 唯一当前方向：最小 Host

项目所有者已决定删除 Host 游戏规则校验和手动规则/线索辅助，仅保留必要游戏状态、统一记录及基本操作。AI 提供分析/建议，说书人负责规则正确性。具体边界见 [最小 Host 产品合同](MINIMAL_HOST_PRODUCT_CONTRACT_2026-10-17.md)。

先删除冗余，允许明确缺口；不要求先完成替代系统。继续保护数据完整性、确认事实、私密信息和过期 AI 响应隔离，这些不属于游戏规则校验。

## 旧轮次收尾

#315–#328 的 Session 收敛、独立 Recovery/重复文字记录删除、状态收敛与 D1–D5a 局部整理作为下一轮基线保留。它们不代表最小 Host 已实现。

旧路线中“保留规则语义，继续拆分夜间信息准备与 AI 生命周期”的 NEXT 已暂停，不再驱动开发。既有合法性/候选/登记投影不得仅因刚拆出或测试通过而保留。

旧实施证据见 [本轮清理规格](MINIMAL_GAME_STATE_CLEANUP_2026-10-17.md)、[D 阶段历史审计](APP_HOST_STAGE_D_AUDIT_2026-10-17.md)、[D5a 检查点](REGISTRATION_OPTIONS_D5A_2026-10-17.md)。历史文档中的未来任务和规则保留要求由新合同覆盖。

## 下一轮顺序

1. 在同步主线的新分支/独立工作区做最小 Host 删除边界审计，尚不继续旧方案提取。
2. 从最小操作流程确定保留状态、记录、UI 和 AI 请求边界，列全生产/测试消费者。
3. 删除整条规则计算、合法候选、登记解释和辅助展示依赖，保持基本游戏操作及数据一致性。
4. 再审计剩余大文件；按实际职责拆分，禁止全局 Context、God State 和把原闭包整体搬走。
5. 单独完善同一记录的必要覆盖和最小中断续局，不恢复精确存档体系。

目前仍无退出恢复、完整复盘或跨局完整归档；事件记录也未覆盖所有必要进度。当前代码不是已经完成的最小 Host。操作环境和交接见 [当前交接](NEXT_DEVELOPMENT_HANDOFF.md)。
