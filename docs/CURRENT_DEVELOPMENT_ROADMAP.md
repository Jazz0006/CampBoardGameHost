## 仍有效的架构边界

- Host/Game Engine 拥有合法性与确认事实；AI 仅建议，未经验证和授权的方案不是事实。
- 当前游戏事实只有一个权威所有者。只读投影不自动等于冗余，也不能变成第二个可写状态。
- UI 草稿和未采纳 AI 计划不是已确认事件。已发布信息保留真实内容、接收者及顺序，不重新生成。
- 删除旧恢复不等于取消持久化；未来只持久化所需权威记录，不恢复旧快照体系。
- 本轮用户已覆盖旧 Recovery 保留条款及“必须先完成替代能力才能删除”的约束。具体实现采用本地目录直接读写。
- 验证遵循 [测试策略](TESTING_STRATEGY.md)；不制造 RED，合并仍需适用的独立 CI/R2。
