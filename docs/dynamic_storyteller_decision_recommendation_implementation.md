# 动态说书人裁定推荐实施说明

## 1. 本轮目标

在已有首夜方案、不可靠信息和二选一信息推荐的基础上，把游戏进行中的自由裁定接入同一类可重现、可解释的推荐流程。

本轮已覆盖：

- 市长夜间死亡裁定：市长死亡、转移给其他玩家、转移后无人死亡；
- 间谍与隐士的夜间逐次登记；
- 间谍触发处女、呆瓜选择间谍等白天登记；
- 隐士被杀手选择时是否登记为恶魔；
- 小恶魔自杀后的爪牙继承选择；
- 猩红女巫强制继承以及中毒时不触发；
- 可靠贤者的合法陪衬推荐；
- 艺术家自由问题的真实答案录入，以及不可靠回答推荐。

玩家自行作出的选择不进入说书人推荐。例如投毒者目标、僧侣保护目标、恶魔击杀目标仍只由应用记录。

## 2. 统一领域模型

`DynamicGameState` 保存推荐所需的不可变事实：

- 当前阶段与轮次；
- 玩家身份、阵营、类型、存活和中毒状态；
- 本夜保护；
- 已使用的一次性能力；
- 历史信息压力；
- 特殊登记次数；
- 可选的公开局势提示。

`DynamicDecisionRequest` 描述当前待裁定事件。候选由 `DynamicStorytellerChoice` 表示，直接后果由 `PredictedDecisionOutcome` 表示。推荐结果统一包含：

- 风格；
- 质量等级；
- 总分；
- 结构化评分项；
- 风险提示。

所有推荐必须先枚举合法候选，再模拟直接结果，最后评分。界面文字不作为领域算法输入。

## 3. 市长推荐

候选包括市长本人和其他全部玩家。其他目标可以是存活玩家、死亡玩家、士兵或僧侣保护目标。

每个候选先解析为：

- 市长死亡；
- 其他玩家死亡；
- 今夜无人死亡。

评分考虑：

- 市长是否进入三人残局；
- 是否通过死亡玩家、士兵或保护制造无人死亡；
- 目标是否还有未使用的高影响能力；
- 目标此前承受的信息压力；
- 目标阵营；
- 可选的公开局势提示。

温和方案偏向直接让市长死亡；平衡方案允许转移，但惩罚高影响空刀和未使用关键能力死亡；激进方案允许更强的无人死亡叙事，并显示风险。

若市长中毒、恶魔中毒或市长已被僧侣保护，市长能力不会产生自由裁定步骤。

## 4. 特殊登记推荐

登记按每次交互生成，不跨能力或跨夜保存。

候选始终包含真实身份。能力正常时，额外包含当前能力允许的间谍或隐士登记：

- 只检测阵营的能力只生成阵营候选；
- 需要具体身份的能力才生成角色候选；
- 中毒的间谍或隐士只有真实身份候选。

洗衣妇、图书管理员和调查员继续使用原有联合推荐，因为“登记、展示角色、真实目标、陪衬”必须作为一个整体评分。独立登记面板仅在没有联合方案时显示通用登记推荐。

白天高影响登记会提高误导压力：

- 处女与间谍；
- 呆瓜与间谍；
- 杀手与隐士。

平衡默认倾向避免未经提示的立即胜负或强确认效果，激进方案仍可提供特殊登记并标注风险。

## 5. 恶魔继承

小恶魔选择自己后，夜间流程新增继承裁定步骤。

- 五名或更多玩家存活且健康猩红女巫在场：候选收窄为猩红女巫；
- 猩红女巫中毒：不触发强制继承；
- 其他情况：枚举全部存活爪牙；
- 平衡方案倾向让已经完成设置效果的男爵或低剩余能力价值爪牙继承；
- 选择投毒者会提示其持续能力丢失。

继承目标在夜间结算前锁定，结算后才真正修改角色并展示新身份。

## 6. 艺术家

应用无法理解玩家自由输入问题的语义，因此采用两阶段流程：

1. 说书人根据魔典输入真实答案；
2. 系统根据艺术家能力是否可靠推荐最终回答。

可靠艺术家只能采用真实答案；醉酒或中毒时保留真实与错误答案，并给出平衡和激进建议。真实答案和实际展示答案均写入事件记录。

## 7. 测试底线

- 市长转移到死亡玩家、士兵或保护目标时解析为无人死亡；
- 新手方案避免无提示的高影响空刀和直接杀死邪恶玩家；
- 中毒特殊角色只能按真实身份登记；
- 阵营检测不生成无意义的多个角色候选；
- 五人以上健康猩红女巫必须继承；
- 中毒猩红女巫不强制继承；
- 有其他选择时，平衡方案避免优先牺牲仍有持续能力的投毒者；
- 完整 Android 单元测试和 Debug APK 构建通过。
