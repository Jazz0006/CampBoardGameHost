## 最新产品决定（覆盖旧文档）

删除 Host 游戏规则校验、线索计算、合法候选枚举、登记解释推导和手动规则/线索辅助。AI 推荐什么，实际确认什么，就记录并展示什么。保留玩家/座位/对局身份、原子记录、重复确认防护、过期响应隔离和私密信息保护；规则正确性由说书人承担。
